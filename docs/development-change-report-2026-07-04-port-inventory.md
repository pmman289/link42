# Link42 端口台账插件测试报告

日期：2026-07-04

## 版本

- Controller：0.5.12
- Agent：0.5.10
- Web：0.4.7

## 本次主要变更

### 移除测试插件

- 已移除旧的 `test-tools` 测试插件。
- 节点插件弹窗中不应再出现“测试插件”入口。

### 新增端口台账插件

- 新增“端口台账”节点插件，用于记录节点对外入口端口占用情况。
- 用户可为每个节点维护一个可用入口端口范围，例如 `23000-23099`。
- 保存端口范围后，会询问是否立即扫描。
- 也可以通过“扫描占用”按钮手动扫描。
- 扫描结果会列出范围内已被占用的端口，但不会自动填写用途。
- 用户可将扫描结果登记到台账中，再自行填写用途。
- 用户可手动添加 TCP/UDP 端口条目。
- 用户可删除条目。
- 支持按端口号、用途、协议、进程名、检测来源模糊搜索。

### WireGuard 端口识别

端口台账扫描除了系统监听端口，还会额外识别 WireGuard 端口：

- `wg show all listen-port`
- `wg-quick` 配置中的 `ListenPort`
- OpenWrt UCI 中的 `network.*.listen_port`

这样可以覆盖 WireGuard 端口不一定显示在普通监听列表里的情况。

### 前端修复

- 修复点击“端口台账”后可能显示空白的问题。
- 切换到端口台账 tab 时会重新读取数据。
- 读取期间会显示“正在读取端口台账...”。
- 搜索过滤对空字段做了防御，避免旧数据或异常数据导致前端渲染中断。

## 建议测试范围

### 插件入口

1. 登录主控。
2. 选择在线节点 `local-port-inventory-demo`。
3. 点击“打开插件”。
4. 确认插件弹窗中有“端口台账”tab。
5. 确认不再出现旧的测试插件。

预期：

- 端口台账 tab 可打开。
- 不应出现空白页面。
- 读取期间应显示加载提示。

### 读取台账

1. 点击“端口台账”tab。
2. 等待读取完成。

预期：

- 起始端口显示 `23000`。
- 结束端口显示 `23099`。
- 台账列表中能看到已有演示记录。

### 保存端口范围

1. 修改端口范围，例如 `23000-23099`。
2. 点击“保存范围”。
3. 在确认框中选择是否立即扫描。

预期：

- 合法范围保存成功。
- 起始端口大于结束端口时应提示错误。
- 端口小于 1 或大于 65535 时应提示错误。

### 扫描占用端口

1. 点击“扫描占用”。
2. 等待扫描完成。

预期：

- 扫描结果应能发现范围内占用端口。
- WireGuard 配置里的 `UDP/23001` 应能被识别。
- TCP/UDP 普通监听端口应能被识别。
- 扫描结果中的用途为空，由用户自行填写。

### 登记扫描结果

1. 在扫描结果中点击“登记”。
2. 查看端口台账列表。

预期：

- 条目被添加到台账。
- 已存在的协议和端口应显示“已登记”或返回重复提示。
- 新登记条目的用途默认为空。

### 手动添加条目

1. 选择协议 TCP 或 UDP。
2. 填写端口号。
3. 填写用途。
4. 点击“添加条目”。

预期：

- 合法条目添加成功。
- 重复协议和端口应提示已存在。
- 超出已配置范围的端口应提示错误。

### 编辑用途

1. 在台账列表中修改某个条目的用途。
2. 输入框失焦。
3. 刷新台账或重新打开插件。

预期：

- 用途保存成功。
- 重新打开后仍显示修改后的用途。

### 删除条目

1. 点击某条记录的“删除”。

预期：

- 条目从列表中消失。
- 刷新后不应再次出现。

### 搜索

1. 搜索端口号，例如 `23001`。
2. 搜索用途，例如 `WireGuard`。
3. 搜索协议，例如 `udp`。
4. 搜索检测来源，例如 `socket`。

预期：

- 列表应按搜索词过滤。
- 清空搜索后显示全部台账记录。

### 离线节点

1. 选择离线节点。
2. 打开插件。
3. 尝试扫描端口。

预期：

- 离线节点不能执行扫描任务。
- 后端直接调用扫描接口也应返回 `409 node is offline`。

## 兼容性说明

- 端口台账扫描任务 `node_plugin.port_inventory.scan` 要求 Agent 版本不低于 `0.5.10`。
- 老版本 Agent 不会上报端口台账能力，前端应显示不可用或缺少能力。
