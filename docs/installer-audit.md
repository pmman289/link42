摘要校验用于检查资源完整性，摘要和资源均由用户自己的主控提供。HTTP 与 HTTPS 均维持兼容；摘要不替代 HTTPS 的传输来源认证。

更新独立 UDP2RAW 安装脚本时应同步更新主控，以提供二进制摘要接口。旧主控缺少摘要时脚本会终止并保留旧程序，不回退到无校验安装；已运行的 UDP2RAW 服务不受影响。

`agent.env` 继续兼容安装器生成的单引号格式及常见双引号、无引号字面值。环境文件中的命令、变量展开和任意自定义变量不再执行或导出；需要的实际值请直接写入对应 `LINK42_*` 键。

自动化测试使用隔离文件、替代命令及本地主控；覆盖安装成功/失败、源码预检失败、摘要不匹配、运行中二进制替换、信号退出、下载大小限制和参数注入。

另在授权测试机 hyhk02 验证了独立服务的新装上线、覆盖安装、强制健康检查失败后的完整恢复及卸载。原有 Agent 进程号保持不变，测试资源已清理。生产发布另行执行。
